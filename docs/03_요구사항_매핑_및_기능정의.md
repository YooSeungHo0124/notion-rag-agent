## 2. 기능 정의 (F0 ~ F7)

### F0. 기반: LLM 어댑터와 프로젝트 골격
- `LLMClient` 인터페이스 아래 `ClaudeCLIClient`(구독, `claude -p --output-format json`)와 `AnthropicAPIClient`(이후)를 둡니다.
- 설정은 `.env`와 `config.yaml`로 관리합니다 (노션 토큰, 모델, 경로).
- **완료 기준:** `python -m app ask "안녕"`이 응답을 돌려준다.

### F1. 노션 수집과 증분 동기화
- Notion API로 연결한 페이지·DB를 순회하며 블록을 Markdown으로 변환합니다.
- 함께 저장할 메타데이터: `page_id, title, url, parent, tags, created/last_edited_time`
- 증분 동기화: 마지막 동기화 이후 바뀐 페이지만 다시 처리하고, 삭제된 페이지는 인덱스에서도 제거합니다.
- **완료 기준:** 두 번째 실행에서 변경분만 처리되고, 그 수가 로그에 출력된다.

### F2. RAG: 청킹, 임베딩, 검색, 근거 답변
- 청킹: 제목(heading) 구조 기준으로 나누고 크기를 제한합니다. 각 조각에 페이지 제목과 경로를 붙입니다.
- 임베딩: `bge-m3` (로컬, 한국어 지원, 무료). 벡터DB: Chroma.
- 검색: 의미 검색에 키워드(BM25)를 섞은 하이브리드 검색, 날짜·태그 필터 지원
- 답변: 출처(노션 URL) 인용을 필수로 하고, 근거가 없으면 "기록에 없음"이라고 답합니다.
- **완료 기준:** "작년에 OOO 어떻게 해결했지?" 같은 질문에 출처 링크가 달린 답이 나온다.

### F3. MCP: 직접 구현과 공식 서버 연결
- 직접 구현하는 `my-memory` MCP 서버:
  - `search_notes(query, k, date_from?, tags?)`
  - `get_timeline(topic)`: 주제별 기록을 시간순으로 정리
  - `get_page(page_id)`
- 노션 공식 MCP 서버(Integration 토큰 방식)로 페이지 생성, 수정, DB 항목 추가
- `claude -p --mcp-config`로 두 서버를 동시에 연결합니다.
- **완료 기준:** Claude가 상황에 맞춰 두 서버의 도구를 골라 호출하는 것이 로그로 확인된다.

### F4. LangGraph 멀티에이전트와 Human-in-the-loop
```
START → Supervisor(의도 분류 + 계획)
          ├─ Retriever  : my-memory 검색
          ├─ Analyst    : 여러 기록 종합, 비교, 회고
          ├─ NotionOps  : 노션 CRUD (쓰기 전 interrupt로 사용자 승인)
          └─ Writer     : 최종 답변 + 출처
        → 필요하면 Supervisor로 돌아가 반복 (최대 N회)
```
- 대표 시나리오:
  1. 질의: "지난달 회의록에서 내 액션아이템 뭐였지?"
  2. 생성: "그걸 할 일 DB에 넣어줘" → 미리보기를 보여주고 승인받은 뒤 생성
  3. 종합: "이번 달 기록으로 회고 초안 페이지 만들어줘"
- **완료 기준:** 세 시나리오가 끝까지 동작하고, 승인을 거절하면 노션에 아무 변경도 생기지 않는다.

### F5. 메모리
- 단기 메모리: LangGraph checkpointer(SQLite)에 대화 스레드별로 저장
- 장기 메모리: 내 프로필(관심사, 진행 중인 프로젝트, 자주 쓰는 DB)을 저장하고 검색 결과를 개인화
- **완료 기준:** 프로그램을 재시작해도 "아까 그거"라는 맥락이 이어진다.

### F6. 평가와 트레이싱 ← 어필의 핵심
- 평가셋: 내 노트로 `{질문, 정답 페이지들, 모범 답 요지}` 30~50개를 만듭니다. "기록에 없는 질문" 10%를 포함합니다.
- 지표:
  - 검색: Recall@5, MRR
  - 답변: 정확도(LLM judge), 출처 정확도
  - 모르는 질문에 "모른다"고 답한 비율
  - 지연시간과 호출 수
- 실험: 청킹 방식, 하이브리드 검색 유무, 리랭킹 유무를 비교해 **수치표로 기록**합니다.
- 트레이싱: 노드와 도구 호출 단위로 로그를 남깁니다 (Langfuse 또는 JSONL).
- **완료 기준:** `eval/results.md`에 실험별 비교표가 있다.

### F7. 인터페이스와 배포
- CLI(기본), FastAPI(`/ask`, `/sync`, `/eval`, localhost 전용), 간단한 웹 UI(선택)
- Docker Compose로 실행합니다. 단, 구독 CLI 인증 정보를 컨테이너에 넣는 것은 피하고, 로컬 실행을 기본으로 합니다.
- **완료 기준:** README만 보고 다른 환경에서도 재현할 수 있다.
