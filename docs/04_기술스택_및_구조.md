# 기술 스택 및 프로젝트 구조 결정 (ADR)

- 작성일: 2026-11-10
- 확인한 로컬 환경:
  - 시스템 Python 3.10.16, `uv` 미설치
  - Docker 및 Docker Compose v5.1.1
  - Node v24, Claude Code CLI 설치됨
  - GPU RTX 5080 16GB, 20코어, RAM 62GB (그중 사용 가능 약 8GB)

---

## 1. 핵심 결정 요약

| # | 결정 | 선택 | 이유 |
|---|---|---|---|
| D1 | 실행 방식 | **앱은 로컬 venv, 인프라만 Docker** | `claude -p`가 내 구독 로그인(`~/.claude`)을 사용합니다. 이 인증 정보를 컨테이너에 넣지 않기 위해서입니다. |
| D2 | Python/venv 관리 | **uv + Python 3.12** (`.venv`) | 시스템 Python이 3.10이라 버전을 분리합니다. uv는 lock 파일로 재현성을 보장하고 설치가 빠릅니다. |
| D3 | LLM | Claude 구독 `claude -p` (어댑터) | 유료 API 비용이 들지 않습니다. `LLMClient` 인터페이스로 API 전환에 대비합니다. |
| D4 | 벡터DB | **Qdrant (Docker)** | dense+sparse 하이브리드 검색과 메타데이터 필터를 기본 지원합니다. 운영 환경과 같은 구성이라 Chroma보다 어필 포인트가 됩니다. |
| D5 | 임베딩 | **bge-m3 (로컬 GPU)** | 한국어를 지원하고, dense와 sparse 벡터를 한 번에 생성합니다(하이브리드 검색에 사용). 비용이 없습니다. |
| D6 | 리랭커 | bge-reranker-v2-m3 (F6 실험용) | 리랭킹 전후 성능을 비교하는 데 씁니다. |
| D7 | 오케스트레이션 | **LangGraph** (+ langchain-core 최소 사용) | 공고에서 가장 많이 요구합니다. checkpointer와 interrupt를 기본 제공합니다. |
| D8 | MCP | Python `mcp` SDK(FastMCP)로 `my-memory` 서버 구현. 노션 공식 서버 `@notionhq/notion-mcp-server`(npx) 사용 | 직접 구현한 서버와 공식 서버 사용을 둘 다 보여줄 수 있습니다. |
| D9 | 노션 수집 | `notion-client` (공식 Python SDK) | 증분 동기화를 직접 제어할 수 있습니다. |
| D10 | 상태 저장 | **SQLite** (동기화 상태, checkpointer, 장기 메모리) | 혼자 쓰는 앱이라 충분하고, 별도 서버가 필요 없습니다. |
| D11 | 트레이싱 | **Arize Phoenix (Docker 1개)** + OpenTelemetry | Langfuse 셀프호스트는 Postgres, ClickHouse, Redis, MinIO가 필요해 사용 가능한 RAM 8GB로는 무겁습니다. Phoenix는 컨테이너 하나로 돌아가고 데이터도 로컬에만 남습니다. |
| D12 | 인터페이스 | Typer CLI(기본) → FastAPI(`127.0.0.1` 전용) | 혼자 쓰는 단계이므로 외부 포트는 열지 않습니다. |
| D13 | 품질 도구 | ruff, pytest, pydantic-settings, pre-commit | |
| D14 | 버전 관리 | git (지금 폴더는 아직 git 저장소가 아님) | |

## 2. 런타임 구성

```
┌────────────── 로컬 (uv .venv, Python 3.12) ──────────────┐
│  CLI / FastAPI(127.0.0.1:8000)                            │
│     └─ LangGraph 그래프 ── LLMClient ── claude -p (구독)   │
│                           └─ --mcp-config                 │
│                                ├─ my-memory MCP (python)  │
│                                └─ notion MCP (npx)        │
│  sync 작업: Notion API → 청킹 → bge-m3(GPU) → Qdrant      │
│  SQLite: data/state.db                                    │
└───────────────────────────────────────────────────────────┘
┌────────────── Docker Compose ─────────────────────────────┐
│  qdrant   : 127.0.0.1:6333 (볼륨 ./volumes/qdrant)         │
│  phoenix  : 127.0.0.1:6006 (트레이스 UI)                   │
└───────────────────────────────────────────────────────────┘
```
모든 포트는 `127.0.0.1`에만 바인딩해서 외부에서 접근할 수 없게 합니다.

## 5. 보안과 개인정보 원칙 (1차)
- `.env`(노션 토큰)와 `data/`, `volumes/`는 git에 올리지 않습니다.
- 노트 원문은 로컬(Qdrant, SQLite)에만 저장합니다. Claude에는 검색된 조각만 전달됩니다.
- 구독 인증 정보는 컨테이너나 레포에 넣지 않습니다.
- 노션 쓰기 작업은 반드시 승인을 거치고, 삭제 대신 보관(archive) 처리합니다.
