# 고객 미팅 메모 - Azure Interior

- 일시: 2026-10-28
- 참석: Azure Interior 구매담당, 당사 Marc(영업)

## 논의 내용

- Customizable Desk 견적 건: 사무실 2층 리모델링용이다. 상판은 **화이트 스틸** 사양을 원한다.
- 요청 할인율은 12%였다. 규정상 본부장 승인 대상이라 당일 확답하지 않았다.
- 납기는 12월 첫째 주 설치를 희망했다. 리모델링 공사 일정 때문에 늦어지면 곤란하다고 했다.
- 5 VP Chairs 건은 임원 회의실용이다. 예산 확정 전이라 내년 1월로 미뤄질 수 있다고 했다.

## 후속 조치

- 본부장에게 12% 할인 승인 요청 (Marc)
- 화이트 스틸 상판 재고와 Wood Corner 리드타임 확인 (구매·물류팀)
