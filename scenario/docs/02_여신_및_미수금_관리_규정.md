# 여신 및 미수금 관리 규정

- 시행일: 2026-07-01
- 담당 부서: 재무팀

## 결제 조건

- 기본 결제 조건은 송장 발행 후 30일이다.
- 신규 거래처는 첫 주문 금액의 50%를 선금으로 받는다.

## 연체 대응

- 만기일이 지난 미수금이 있으면 해당 거래처의 **신규 견적 확정을 보류**한다. 영업사원은 견적을 보낼 수 있지만 주문 확정(Confirm)은 재무팀 확인 후 진행한다.
- 연체 14일 이상: 담당 영업사원이 거래처에 직접 연락하고 CRM에 활동으로 기록한다.
- 연체 30일 이상: 재무팀장에게 보고하고 출고를 중단한다.
